⚠️ Prerequisite: Run SQL Migration First

Before seeding users, you must run the database migration in Supabase SQL Editor:

  1. Go to Supabase Dashboard → SQL Editor
  2. Open the file supabase/migration_v9.sql from this project
  3. Copy all SQL and paste into SQL Editor
  4. Click Run
  5. Wait for "Success" message

Step 1: Seed Demo Users

This creates 16 demo user accounts, one for each role type.

Step 2: Seed Stock Data

This adds realistic construction materials across all 11 sites with varying quantities.

Step 3: Launch App

Once users and stock are seeded, open the main app and login.
